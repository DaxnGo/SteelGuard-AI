## 2. Preprocessing and augmentation

Pascal VOC boxes are validated against each image size and converted to
normalised YOLO `class cx cy width height` rows. Ultralytics loads the grayscale
JPEGs as three-channel images, converts them into the model tensor, scales pixel
values to `[0, 1]`, and applies aspect-ratio-preserving letterbox resize/padding.

The committed training configuration uses:

| Setting | Value |
| --- | ---: |
| `hsv_h` | 0.015 |
| `hsv_s` | 0.7 |
| `hsv_v` | 0.4 |
| `degrees` | 0.0 |
| `translate` | 0.1 |
| `scale` | 0.5 |
| `fliplr` | 0.5 |
| `flipud` | 0.0 |
| `mosaic` | 1.0 |
| `mixup` | 0.0 |
| `copy_paste` | 0.0 |

Augmentation is training-only. Validation and test data are not augmented.

## 3. Reproducing a fresh run

Use Python 3.11 from the repository root. The reference CPU environment pins
PyTorch and Ultralytics in `backend/requirements.txt`. A GPU environment must
record its exact PyTorch/CUDA build in the resulting report.

```powershell
python -m pip install -r backend/requirements.txt

python -m ai.train_eval_pipeline prepare `
  --raw-images C:\path\to\NEU-DET\IMAGES `
  --raw-annots C:\path\to\NEU-DET\ANNOTATIONS `
  --source-archive C:\path\to\NEU-DET.zip `
  --output-dir datasets\NEU-DET `
  --audit-report ai\evaluation\dataset_audit.json

python -m ai.train_eval_pipeline train `
  --model yolo11n.pt `
  --data ai\dataset_neu.yaml `
  --epochs 100 --patience 20 --batch 16 --imgsz 640 `
  --device 0 --workers 4

python -m ai.train_eval_pipeline evaluate `
  --weights runs\detect\neu-det-yolo11n\weights\best.pt `
  --data ai\dataset_neu.yaml `
  --batch 16 --imgsz 640 --device 0 `
  --report ai\evaluation\evaluation_summary.json
```

The downloaded YOLO11n base artifact used during the 2026-08-25 pipeline probe
was 5,613,764 bytes with SHA-256
`0ebbc80d4a7680d14987a577cd21342b65ecfd94632bd9a8da63ae6417644ee1`.
Record and verify this hash before a final training run.

The `evaluate` command verifies class order, evaluates only `split=test`, writes
overall and per-class precision/recall/F1/mAP to JSON, records runtime and
checkpoint metadata, and asks Ultralytics to render its confusion matrix and
batch plots under ignored `runs/` output.

A diagnostic run of the evaluator against that new split completed successfully

A final report can be promoted only after a fresh checkpoint is trained from the
committed split and `evaluation_summary.json`, confusion matrix, and reviewed
failure examples are produced from its untouched 180-image test set.

## 6. Model choice

YOLO11n remains the provisional candidate because it is already integrated,
matches the six-class detection contract, has approximately 2.59 million
parameters and 6.5 GFLOPs at 640 pixels, and completed the measured CPU
inference-plus-Grad-CAM path with 571.66 ms median latency and 575.59 MiB peak
RSS on the demo host.

Larger YOLO11 variants and unrelated detector families have not been trained on
the same committed split. Claiming that they are less accurate or that YOLO11n
is the final accuracy winner would therefore be unsupported. Larger candidates
are deferred because they increase memory and latency before any domain-metric
benefit has been demonstrated. Final model selection requires a same-split
candidate comparison or explicit approval that the measured YOLO11n result
meets the product threshold.

## 7. Inference metadata and Grad-CAM

The deployed adapter converts uploads to RGB and letterboxes them to 640 x 640
with padding value 114. Deployment confidence defaults to `0.25`, but remains an
environment setting that must be calibrated after held-out evaluation. Runtime
uses Ultralytics `8.4.127` and PyTorch `2.12.1+cpu` in the backend image.

`ModelEngine.predict()` hooks the C2PSA layer at model index 10, immediately
before the first Upsample at index 11. The selected class score and the Grad-CAM
gradient come from the same forward pass. Full technical evidence, checksum
validation, hardware, latency, and memory results are recorded in
`ai/TECHNICAL_EVIDENCE.md`.

## 9. Known limitations and tested hardware

- NEU-DET contains small grayscale laboratory crops and does not establish
  performance on production cameras, colour images, mixed defects, or changing
  illumination/material conditions.
- One source image duplicate and three duplicate annotation boxes required
  deterministic removal.
- Upscaling 200 x 200 source images to 640 x 640 adds no new visual detail.
- The current checkpoint was trained at 224 pixels on an unknown split.
- No held-out test metrics, per-class errors, or calibrated production threshold
  are currently available for the bundled checkpoint.
- CPU demo hardware: Intel Core i3-7020U, four logical CPUs, Docker Desktop/WSL2.
- A CPU training probe at 224 pixels measured roughly 19 seconds per batch; a
  complete retraining run was not represented as complete.
- The host has an NVIDIA GeForce MX130 with 2 GB VRAM, but the exact CUDA
  training environment could not be installed safely with the available disk
  space. No GPU training result is claimed.
